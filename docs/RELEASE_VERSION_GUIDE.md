# Регламент синхронизации версий и руководство по обновлению DroneFlames PC Port

Настоящий регламент описывает порядок изменения версии игры, полный перечень файлов проекта, где зафиксированы строки версий, а также архитектуру и работу парсера раздела **«Что нового»** (`WHATS_NEW`).

---

## 1. Контекст проблемы (Рассинхрон v0.33.5.4 и v0.33.5.2)

В текущей версии игры обнаружено расхождение номеров версий в интерфейсе:
- **Заголовок окна (Window Title / Taskbar):** `DroneFlames v0.33.5.4 (PC Port by @droneflamesmod)`
- **Футер в главном меню (Footer Label):** `v0.33.5.2 (PC Port by @droneflamesmod)`

> [!NOTE]
> Согласно решению команды, отдельный хотфикс ради текстовой надписи в продакшн не выпускается. Все расхождения будут синхронизированы в рамках следующего планового обновления по приведенному ниже чеклисту.

---

## 3. Чеклист релиза (Release Checklist)

Перед формированием релизного коммита и сборкой архивов выполните следующие шаги:

- [ ] **Шаг 1: Фиксация целевого номера версии**
  - Определите версию в формате `X.Y.Z.W` (например, `0.33.5.5`).
- [ ] **Шаг 2: Обновление конфигурации движка**
  - Задайте имя проекта в `project.godot`: `DroneFlames v{VER} (PC Port by @droneflamesmod)`.
  - Задайте параметры версий в `export_presets.cfg`.
  - Обновите `version_info.json`.
- [ ] **Шаг 3: Обновление UI и логов изменений**
  - В `ui/menus.gd` измените `const VERSION = "v{VER} (PC Port by @droneflamesmod)"`.
  - В `ui/menus.gd` в массив `const WHATS_NEW` добавьте новые пункты в начало списка (см. раздел 4).
  - Обновите `net/github_updater.gd` (`current_version`).
  - Обновите `watermark.gd`.
- [ ] **Шаг 4: Обновление скриптов сборщика и документации**
  - Обновите функции возврата версии в `build.py` и `build_test.py`.
  - Обновите `#define MyAppVersion` в `installer.iss`.
  - Обновите `Start_DroneFlames.bat` и бейдж в `README.md`.
  - Обновите ассерты в `dev/test_title_icon.gd`.
- [ ] **Шаг 5: Проверка автотестами**
  - Запустите Godot в headless-режиме:
    ```powershell
    godot --headless --script dev/test_title_icon.gd
    ```
  - Убедитесь, что все ассерты пройдены без ошибок.
- [ ] **Шаг 6: Сборка релизных пакетов**
  - Запустите скрипт сборки:
    ```powershell
    python build.py
    ```

## 4. Архитектура и устройство парсера «Что нового» (`WHATS_NEW`)

Окно «Что нового» появляется автоматически, когда игрок запускает новую версию игры. Это контролируется методом:
```gdscript
if Save.load_seen_version() != VERSION:
    _show_whats_new()
```
После закрытия окна вызывается `Save.set_seen_version(VERSION)`, чтобы не беспокоить игрока при повторных запусках.

### 4.1. Формат записей в `WHATS_NEW`
Массив `const WHATS_NEW: Array = [...]` содержит строки следующего формата:
`"КАТЕГОРИЯ v{VER}: Описание изменений, разбитое точками с запятой"`
или
`"КАТЕГОРИЯ v{VER} — Описание изменений"`

### 4.2. Разделение заголовка и описания (`_wn_split`)
Метод `_wn_split(text: String) -> Array` ищет разделитель (`" — "` или `": "`), начиная с 7-го символа:
- **Нулевой элемент:** Заголовок пункта (например, `"ИНТЕРФЕЙС & ВИДЕО v0.33.5.2"`).
- **Первый элемент:** Описание изменения с гарантированной первой заглавной буквой (`rest.substr(0, 1).to_upper() + rest.substr(1)`).

### 4.3. Автоматическая группировка по разделам (`_wn_group`)
Каждая строка автоматически относится к одной из 4 категорий на основе ключевых слов:

| ID группы | Название категории | Ключевые слова и правила |
|-----------|--------------------|--------------------------|
| **0** | **Геймплей и механики** | Содержит: `фронт`, `прохода`, `РАЗРУШ`, `окоп`, `наступ`, `армий`, `война`, `Флот`, `корабл`, `Корабел`, `КР `, `ПВО`, `Дроны`, `БПЛА`, `ОТРК`, `удар`, `Конво`, `баллист` |
| **1** | **Карты и генерация** | Содержит: `карт`, `рек`, `озёр`, `остров` |
| **2** | **Исправления и оптимизация** | Начинается с `ИСПР:` или содержит: `исправл`, `застрева`, `больше не`, `не мерцает`, `не перекрывают`, `не уплывают`, `не мешают`, `без абсурдных`, `надёжно`, `баг`, `пишет, чего не хватает`, `не теряет`, `не пропадает` |
| **3** | **Новые функции и интерфейс** | Начинается с `НОВОЕ:` или является категорией по умолчанию (fallback) |

### 4.4. Интеллектуальный подбор иконок (`_wn_icon`)
Для каждого пункта парсер перебирает соответствия из массива `WN_ICONS`:
- `"фронт"` → `icon_stance_attack`
- `"окоп"` → `icon_trench`
- `"Боты"` → `si_bots`
- `"прохода"` → `icon_treaty_passage`
- `"карт"` → `si_size`
- `"рек"` → `si_rivers`
- `"РАЗРУШ"` → `icon_demolish`
- `"Бомбард"` → `icon_bomber`
- `"ТЭЦ"` → `icon_power`
- `"мир"` → `icon_rel_truce`
- `"дипломат"` → `icon_rel_ally`
- `"Звук"` → `si_daynight`
- `"вылет"` → `si_mode`
- **Fallback (по умолчанию):** `emb_star` (золотая звезда).

### 4.5. Пример добавления нового пункта
При выпуске версии `v0.33.5.5` добавьте в начало `WHATS_NEW` строки:
```gdscript
"СЕТЕВАЯ ИГРА & МОДЫ v0.33.5.5: автоматическая синхронизация модов с хостом, диалог скачивания недостающих модов перед входом, плавный прогресс-бар загрузки",
"ИСПРАВЛЕНИЯ v0.33.5.5: устранена ошибка синтаксиса mod.gd в моде Ядерного удара, оптимизирован сетевой протокол сжатия DEFLATE",
```
Благодаря ключевым словам `"СЕТЕВАЯ ИГРА & МОДЫ"` строка автоматически получит категорию 3, а строка с `"ИСПРАВЛЕНИЯ"` — категорию 2.
